# QualityForge AI roadmap

- [x] M1: typed Playwright foundation, fixture layer, page object, API client, example tests, reporting, CI and documentation
- [ ] M2: WarrantyBox staging adapters, authentication and purchase flows, document lifecycle, authorization and deletion checks
- [ ] M3: optional AI receipt evaluation against deterministic synthetic ground truth; diagnostic failure summaries
- [ ] M4: Appium on Android/iOS, browser push instrumentation, negative network tests, selected OWASP controls
- [ ] M5: reusable adapters, richer examples, contributor guide, published package and validated public release

**Definition of done for M1:** npm dependencies install, typecheck succeeds, all sample test projects pass in CI, reports upload, and an independent developer can clone and reproduce the tests. Treat this as pending until a successful CI run is recorded.
